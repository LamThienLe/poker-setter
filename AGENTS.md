# Project docs — read these first

`.helper/` holds the working docs for this project. Read all of them before
starting work:

- `.helper/codestyle.md` — spacing, naming, comments, components, currency.
  Follow it; it is not optional.
- `.helper/roadmap.md` — what is done and what is planned.
- `.helper/progress.md` — the change log. **Append an entry for any change you
  make**, newest at the top, and move the `(latest)` marker.
- `.helper/testing.md` — how to test locally and on a phone, the pre-release
  checks, how to release, and how to roll back.

There is no `helper/` directory any more — it was merged into `.helper/`.
