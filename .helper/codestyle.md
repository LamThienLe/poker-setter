# Poker Settler — Code Style

## Spacing
- Functions, methods, and classes separated by two blank lines
- No extra blank lines inside functions

## Naming
- Descriptive, self-explanatory names — no abbreviations
- camelCase for variables/functions, PascalCase for components/types

## Comments
- Only for complex logic (e.g. the settlement algorithm)
- Skip where code is self-explanatory

## Components
- Short, focused — one responsibility per component
- Tailwind only — no external component libraries

## Currency
- All amounts in candies (🍭), integers only (no floats)
